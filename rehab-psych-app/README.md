# 五分钟同行 · 康复心理学互动体验

一个基于《Handbook of Rehabilitation Psychology》（第 3 版, APA 2019）内容编写的
交互式学习小应用。单文件 HTML, 双击即可用浏览器打开, 不需要联网、不需要安装任何东西。

## 怎么玩

1. 双击 `康复心理学·五分钟同行.html`
2. 给要陪伴的人起个名字（可以留空）
3. 用 15 秒安放一下自己
4. 走完 5 个片段, 每个片段做 1 个回应选择
5. 看总结, 收集到的卡片会留在「工具箱」里

- 全程约 4 分钟; 想继续可以点「加练一幕」（总共仍在 5 分钟以内）
- 键盘 1 2 3 可以直接选, Enter 继续, Esc 关闭工具箱
- 没有分数, 没有失败。任何选择都会收到一张视角卡片和一段解释,
  也可以点「换个回应再看看」比较不同做法

## 它想传达的康复心理学视角

| 片段 | 核心概念 |
|---|---|
| 沉默的病房 | 以人为中心的倾听; 先连接再行动 |
| 评定会 | ICF 生物心理社会模型（身体功能 / 活动 / 参与 + 环境与个人因素）|
| 门口的三级台阶 | 人—环境交互; 环境是可改变的杠杆 |
| 一杯水的距离 | 自我效能与亲历的成功体验; 微目标阶梯 |
| 我这一生还有什么用 | 优势视角与意义重构; 幸福感与茁壮成长 |
| 新来的女孩（加练）| 同伴支持与自主选择 |

## 内容出处

全部概念来自原书, 主要对应：引言; 第 1 章（胜任力本位实践）; 第 4 章（评估）;
第 5 章（干预 / PANEP 框架）; 第 9 章（残疾的社会心理学）; 第 12 章（家庭）;
第 13 章（老化与残疾）; 第 29 章（社区本位康复）。
应用内「工具箱 → 知识来源」有逐条对照。

## 说明

这是一份学习与自我反思的工具, 不是临床建议, 也不能替代专业评估与治疗。
如果在使用中触动了你自己的经历, 请温柔对待自己, 并寻求可信任的人或专业人员。
